## 1. 性格の二軸化

**変更点**
- 冒険者の性格を二つの軸に分けた
  - 探索（大胆／慎重／臆病）：持ち帰る量、負傷しやすさ、冒険記の一文に効く
  - 取引（がめつい／正直／お人好し）：言い値の高さ、値切りの通りやすさ、前金に効く
- 画面には「大胆、がめつい」のような二語の人物評だけを出す

## 2. 店の評判

**変更点**
- 評判は 0〜100 で、50 から始まる。帳場札の中央に語で表示する
  - 80以上「名声」、60以上「好評」、40以上「無名」、20以上「不評」、それ未満「悪名」
- 評判の上がり下がり
  - 言い値で買い取る：＋1
  - 値切りが通る：−1
  - 値切りが通らない：−4（その冒険者の信頼も2段下がる）
  - 断る：−2
  - 申し出を放っておいて一日を締める：1件につき −2
- 評判が高いほど値切りが通りやすく、新しく来る冒険者の初めの信頼も高い

**試算の結果**
指示書の数値のままでは、「毎回値切る」が明らかに得でした。機械的な戦略で各3000回遊ばせ、数値を調整しました。

| 戦略 | 調整前の勝率 | 調整後の勝率 | 調整後の平均評判 |
|---|---|---|---|
| 相手の取引の性格を見て値切る（お人好しだけ） | 91.7% | **76.2%** | 45.0 |
| 言い値で買い続ける | 85.4% | 69.4% | 67.2 |
| でたらめに値切る | 89.2% | 70.2% | 25.1 |
| 毎回値切る | 90.5% | 66.1% | 1.3 |

指示書の狙いは次の2つで、どちらも満たしています。
- 毎回値切っても、値切らないより明らかに得にはならない
- 相手を見て値切るのが最も高く、勝率がおよそ7〜8割

**指示書から変えた数値**
- 新しく始めたときの借金：1000枚 → 1200枚
- 値切りの成功：2割引 → 2割5分引
- 値切りの失敗：評判 −3 → −4。信頼は2段下がる
- 評判が値切りの成否に効く強さ：2倍にした
- 値切りの通りやすさの基本値：がめつい 0.10／正直 0.20／お人好し 0.80
- 信頼による言い値の差を広げた

数値はすべて `index.html` 冒頭の `CONFIG` と `TRAITS` にまとめています。

**試算で分かったこと**
- 手持ちを考えずに出資しすぎると、冒険者が持ち帰った品を買い取る金が足りなくなる。断れば前金が丸損になり、大きく負ける
- 売れる品を倉庫に溜めておくのも不利。1つずつ小出しに売る機械は、勝率がおよそ12点下がった

## 3〜5. 画面の作り直し

**変更点**
- 本日の帳簿：見出しを押すと開閉する。初めは閉じ、見出しに件数を出す。画面を描き直しても開閉の状態は保つ
- 画面下の切り替え
  - 台帳の下端から付箋が覗く形にした
  - 開いている付箋は紙とつながって見える
  - 買取の申し出がある間は、帳場の付箋に件数の印が付く
  - 古い iPhone で付箋の色が抜けないよう、色の指定に備えを入れた
- 売る数の指定
  - 品ごとに −／＋・全部・売る の釦を置いた
  - 「3つで 39枚」のように、値下がり込みの受取額を先に出す
  - 釦はどれも44px以上の大きさにした
  - 見積もりと実際の受取額が一致することを確かめた
  - 「売る」の素早い二度押しで続けて売れないよう、同じ品は0.7秒間受け付けない

## 6. ダブルタップ拡大止めの予備策

**変更点**
- 予備の仕掛けが効く部品に、帳簿の見出しを加えた
- 新しい釦（−／＋・全部・売る、付箋）にも効くことを確かめた。連打で押した回数だけ数が増える
- レビューで、以前加えた押し直しの仕掛けの一つに問題が見つかった。実機では出番がなく、別の釦を押してしまう恐れがあったため外した

## 保存データ

- 保存データの形を ver 2 に上げた
- v0.1.x の保存は、端末内のものも控えの文字列も、そのまま読み込める
  - 性格は次のように読み替える：強欲→大胆・がめつい、豪胆→大胆・正直、正直→慎重・正直、慎重→慎重・正直、臆病→臆病・お人好し
  - 評判は50から始まる
  - 借金はその時点の額のまま。新しく始めた帳場だけが1200枚になる

- 読めなかった保存データ（画面が描けないものも含む）は、新しい帳場で上書きする前に別の名前で取っておく
- 壊れた控えを読み込もうとしたときは、読み込みを断り、今の帳場をそのまま残す
