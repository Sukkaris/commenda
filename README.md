# Commenda: Delve & Dividend

冒険者に出資してダンジョンを探索させ、戦利品を買い取って借金を返す商人の遊戯。試作（v0.1.x）。

## 遊び方（iPhone）
1. このフォルダをGitHub Pagesなど、https で配信できる場所に置く
2. iPhoneのSafariで開き、共有メニューから「ホーム画面に追加」
3. ホーム画面のアイコンから起動する

ホーム画面に追加して遊ぶと、Safariの自動消去の対象外となり保存データが残りやすくなります。念のため、設定画面の「控えをファイルに保存」も時々お使いください。

## 調整
遊び心地の数値は `index.html` 冒頭の `CONFIG` と `TRAITS` にまとめてあります。
